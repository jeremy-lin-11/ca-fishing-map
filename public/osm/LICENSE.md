# OpenStreetMap extract

The files in this directory (`index.json`, `t/*.json`) are extracted from OpenStreetMap by
`scripts/extract-osm.mjs`: named trails (`highway=path|footway|bridleway`), lakes (`natural=water`) and
streams/rivers (`waterway=river|stream`) in California, with geometry simplified and re-encoded.
